Como futuro administrador de sistemas, me apasiona el software libre, la automatización de despliegues y la seguridad en infraestructuras de red. Mis principales áreas de interés técnico incluyen:

* **Servidores Web y de Aplicaciones:** Configuración avanzada de **Nginx** y Apache para entornos de producción en alta disponibilidad.
* **Desarrollo Backend:** Despliegue, gestión y optimización de aplicaciones escritas en **PHP** y conexión con bases de datos relacionales.
* **Control de Versiones y CI/CD:** Utilización profesional de **GitHub** para el versionado de código, automatización de tareas y publicación de documentación técnica con **MkDocs**.
* **Sistemas Operativos:** Hardening y administración de entornos GNU/Linux y Windows Server.
